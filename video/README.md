# video/

Everything for the Devpost / demo video.

- `SKIT.md` - the beat sheet and shot list. Start here.
- `PRODUCTION.md` - where each frame comes from: shot, burned through `hawkeye_vision`, or generated.
- `plates/` - raw camera-feed recordings, clean and unoverlaid. Gitignored.
- `burns/` - the same plates with the real tracker overlay burned in. Gitignored.
- `audio/reference-911-call.wav` - reference 911 call, 3:19, extracted from the source mp4.
  **Local only, and gitignored.** This repo is public and the caller is a named thirteen year old girl,
  which is `docs/research/footage.md` rule 4 exactly. Keep your own copy; do not commit it.
  **Reference only. Do not cut this into the film.** See the sourcing note in `SKIT.md`.
- `audio/reference-911-call.transcript.txt` - timestamped transcript of the above, for matching cadence when we re-perform it.

B-roll licensing rules live in `docs/research/footage.md` and apply to everything here.
Blender and cinematic rendering guidance lives in `media/CLAUDE.md`.
